A closer look.
gilbrt audits authorized websites using bounded, same-origin requests. This interface uses the same audit engine as the CLI, including static checks and optional installed local AI models.
Findings are review candidates. Reports stay redacted. Passive audits do not execute JavaScript, log in, validate secrets, or run active staging probes.
Settings are saved on this device. Audit targets, findings, and source bodies are not saved automatically. Export a report if you want to keep it.
