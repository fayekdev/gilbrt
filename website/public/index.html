Release check

Run against your staging site.

Check security headers, TLS, and credential candidates before promoting a release.

  • Bounded to 25 resource attempts
  • Static source and header checks
  • Redacted HTML report
Terminal
gilbrt --url https://staging.your-domain.example --confirm-authorized --search headers,tls,api-keys,tokens,passwords,private-keys --max-pages 25 --output release-review.html --format html

Replace the example target with a website you’re authorized to audit.
